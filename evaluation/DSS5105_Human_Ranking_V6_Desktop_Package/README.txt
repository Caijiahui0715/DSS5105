V6 desktop-first ranking questionnaire
1. Extract this ZIP.
2. In Google Drive, create a folder, e.g. DSS5105_V6_Images.
3. Upload ALL 30 PNG files from images/ into that folder (not the ZIP itself).
4. Open the folder in Google Drive and copy its ID from the URL after /folders/.
5. Open script.google.com and paste the .gs source into Code.gs.
6. Replace IMAGE_FOLDER_ID with the actual folder ID.
7. Save and run createDSS5105RankingV6; approve Drive and Forms permissions.
8. Find two edit and two respondent links in Execution log.
9. Open both respondent links, test A01 and G02, verify images, labels and ranking options.
10. Each case is a separate page. Equal ranks are allowed.
11. Google Forms may display images at reduced width; reviewers can click images to enlarge when supported.
12. Source: V5 embedded data; no additional property facts were invented.
13. This is a pilot. Check translation and candidate data before formal distribution.
